## 0. 這門課是什麼

繁體中文的行草書法課程,從文房執筆一路到四家法帖的深入臨習。使用者指名的目標:**王羲之、王獻之、米芾、黃庭堅、孫過庭**。內容全部策展自 YouTube 第三方公開影片,本站只做選片、驗證與連結。

語言:**中文是主場**(與音樂課相反)。骨幹頻道:**陳忠建**(逐字示範系列,蘭亭序/聖教序/十七帖/書譜/蜀素帖/松風閣/諸上座/寒山子龐居士詩全有)、**黃簡講書法**(系統筆法講座)、**北大書法公開課**(頻道「北大人」「君子居」,講座型,王獻之的洞靠它補)。簡體來源內容好就收,`lang` 標 `zh`;英文只在真正有價值時用(博物館級素材),`lang` 標 `en`。

## 2. 章節資料檔 schema

```jsonc
{
  "chapter": "CH1",
  "title": "章節標題",
  "units": [
    {
      "id": "ch1-u1",              // 必填,全課唯一
      "name": "單元名稱",           // 必填,繁中
      "type": "skill",             // skill / concept / master(見 §3)
      "assessment": "……",          // skill 與 master 必填,≥80 字(見 §4)
      "lesson": {
        "title": "影片原標題(照 oEmbed 回傳照抄)",
        "channel": "頻道名(照抄)",
        "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
        "lang": "zh",
        "why": "為何選這支(繁中 1-2 句)"
      },
      "drills": [
        {
          "name": "項目名稱(繁中)",
          "kind": "walkthrough",    // 見 §3
          "target": "中鋒、提按",    // 頓號分隔的名詞
          "title": "影片原標題",
          "channel": "頻道名",
          "url": "https://www.youtube.com/watch?v=XXXXXXXXXXX",
          "note": "……"             // 僅在 url 為 null 時必填
        }
      ]
    }
  ]
}
```

找不到合格影片:`url: null` + `note` 寫清楚查過哪些關鍵字、為什麼不合格。**留白是誠實,捏造連結是最嚴重的失敗。** 不要寫 `duration`/`views`。

## 3. 列舉值(只能用這些)

**`type`**
| 值 | 意義 | assessment |
|---|---|---|
| `skill` | 技法單元:可動筆自我檢驗的能力 | 必填 |
| `concept` | 觀念單元:文房知識、書史、理論 | 不寫 |
| `master` | 法帖研究單元:一件(組)法帖的臨習與研究 | 必填(臨帖比對式,見 §4) |

**`kind`**
| 值 | 意義 |
|---|---|
| `theory` | 講解:筆法原理、書史、書論 |
| `walkthrough` | 示範:寫給你看(逐字示範屬此類) |
| `practice` | 跟寫:可以跟著動筆的練習 |
| `pitfall` | 常見錯誤、迷思 |
| `appreciate` | 賞析:高清全帖欣賞、博物館導覽、紀錄片 |

## 4. `assessment` 怎麼寫

讀者**可自己執行、有具體判準**的檢驗方法。≥80 字,含數字或可觀察現象;禁用「適當」「正確地」「良好」「必要時」「確保」;破折號(——)每段最多 1 個。

- 技法單元範例:「鋪紙寫十個『一』字,每筆刻意先藏鋒起筆再中鋒行筆。寫完把紙翻到背面對光看:中鋒的筆畫墨色應集中在筆畫中軸,若墨色偏向單側超過一半的字,表示行筆時筆桿倒向該側,回去把筆桿豎直、放慢一半速度再寫十個。」
- 法帖研究單元寫**臨帖比對式判準**:「對臨蘭亭序前四行,寫完與原帖並排:逐字比對大小比例與傾側方向,標出差最遠的五個字;那五個字用雙鉤把原帖字形描一次,找出你漏看的筆勢(多半是起筆角度與牽絲方向)。連續三次對臨,差最遠的字不重複出現才算過關。」也可用識讀測驗(遮住釋文認出十個草字、說出某字的草法來源)。

## 5. 影片驗證(硬規則)

每支寫進 JSON 的影片都必須先經 oEmbed 實打回 200:
```bash
curl -s "https://www.youtube.com/oembed?url=https://www.youtube.com/watch?v=VIDEO_ID&format=json"
```
- 200 → `title`/`channel` 照回傳照抄;401/403/404 → 換一支
- 搜尋用 `yt-dlp "ytsearch15:關鍵字" --flat-playlist --print "%(id)s|%(duration)s|%(view_count)s|%(channel)s|%(title)s"`,再逐支 oEmbed 驗證
- **絕不憑記憶寫 video ID**;zsh 批次迴圈有 word-splitting 陷阱,用 Python 腳本
- 長度界線:主課 1:00–45:00、drill 0:30–25:00;觀看數 <300 會被警告(內容獨一無二可破例,回報時說明)
- **陳忠建的逐字系列一集通常只講一個字**:選集數時挑「該帖最具代表性、或最能示範該單元主題的字」的那幾集,`name`/`why` 寫清楚選這個字的理由;也可用他的整帖總論/首集當 lesson
